# SQA Plan mínimo — SauceDemo

## Propósito

Verificar que las funciones principales funcionen correctamente y detectar problemas utilizando pruebas automatizadas.

## Alcance

Se prueban las funciones principales de la aplicación, también se prueba diferentes comportamientos de usuarios.

## Herramientas

Playwright con TypeScript, Visual Code.

## Criterio de salida

Se considera listo cuando los test se ejecutan correctamente, no existen fallos.
