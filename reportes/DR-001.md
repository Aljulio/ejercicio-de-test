# DR-001 — Reporte de Defecto

**Título:** El badge del carrito no coincide con el valor esperado tras agregar un producto

**Severidad:** Media
**Prioridad:** Media

## Pasos para reproducir
1. Iniciar sesión con el usuario `standard_user`.
2. Agregar el primer producto del inventario al carrito.
3. Verificar el valor del badge del carrito (`.shopping_cart_badge`).

## Resultado esperado
`"2"` — valor que se forzó intencionalmente en el test (`tests/clase07.spec.ts:107`).

## Resultado obtenido
`"1"` — valor real que muestra el sitio en `.shopping_cart_badge`.

## Evidencia

- **Test:** `Comparar estados antes y después de una acción` — `tests/clase07.spec.ts:91`
- **Paso que falló:** `Expect "toHaveText" locator('.shopping_cart_badge')` — línea `clase07.spec.ts:107`, tras 5.0s de espera (timeout).
- **Trace Viewer:** el elemento `<span class="shopping_cart_badge" data-test="shopping-cart-badge">` se resolvió 14 veces durante el reintento, siempre mostrando `"1"`.
- **Screenshot del reporte HTML:** muestra el ícono del carrito con el badge en `"1"` justo después de hacer clic en *"Add to cart"* del primer producto del inventario.
- **Video y trace.zip:** disponibles en `test-results/` para esta ejecución (`npx playwright show-report`).

## Nota

Este defecto fue **simulado a propósito**, cambiando `toHaveText('1')` por `toHaveText('2')` en el test, con fines de práctica de captura de evidencia de un fallo real. El valor correcto del sistema es `"1"`; el cambio se revirtió en `tests/clase07.spec.ts` una vez documentada la evidencia.
